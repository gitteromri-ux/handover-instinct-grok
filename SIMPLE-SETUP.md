## B. GROK BOT — 6 steps

**B1. Get the app.** On your computer open https://x.ai/bot and click the download for Mac or Windows. Install it and open it. (Phone app: search "Grok Bot" in the App Store / Google Play and sign in the same way later.)

**B2. Sign in.** Click **Get started** / **Sign in**. A browser window opens. Choose **Continue with Google** and pick **gitter.omri@gmail.com**. If it says "create account", say yes — that is the account Grok Bot uses (it is called a Cursor account; you do not need to do anything with it). Close the browser, go back to the app.

**B3. Give it a plan (one of two):**
- If you already pay for Grok (SuperGrok) at grok.com: on the plan screen click **Link Grok Account**, sign in with the same login you use at grok.com, come back. Done.
- If you do not: on the same plan screen choose the trial / Pro option and enter a card (about $20/month for the basic plan). Done.
Wait a minute while it says it is setting up your computer.

**B4. Create the bot.** Click **New → Create new Bot**.
- Name: `General`
- Job: `Operate Omri Gitter's marketing, websites, tracking and reporting for Gita Agency`
- Description — paste this whole block:

```
You are Omri Gitter's always-on operator for Gita Agency (Longevity Life Academy, French Atelier, Club Italia). First action, before anything else, on your computer run:
  git clone https://github.com/gitteromri-ux/handover-instinct-grok.git ~/handover
  git clone https://github.com/gitteromri-ux/handover-master.git ~/handover-master
Then read ~/handover/GROKBOT.md completely and follow it step by step: read every file it lists, sign in to every service in its section 3 (ask Omri to take over the screen only at a login wall, one service at a time, with the exact link), check every live website in section 4, create the routines in section 5, and send the first message in the shape of section 7.

Save ~/handover/rules/operator-os.md, change-safety.md, meta-ecom-playbook.md, tracking-capi.md and ~/handover/_global-rules.md as a permanent skill that loads on every task. Non-negotiable forever: label every claim VERIFIED / USER-REPORTED / ASSUMED; never a number that can include test or QA orders; no live change on Meta, websites, DNS, Vercel, Cloudflare, ActiveCampaign, checkout or real emails without Omri's explicit "go" for that exact item; write the four Army General gate answers before any decision-critical recommendation; touch nothing in the GOLDEN freeze list before 26 Oct 2026; after every change append a dated entry to _today-log.md in handover-master and push; Hebrew when Omri writes Hebrew; short, number-led, no apologies, no progress narration, never a menu without a recommendation.
```
Click **Create**.

**B5. Start it.** In the bot's chat type: `Go. Start with GROKBOT.md.` and send.
When it says it needs you to sign in: click **Agent Computer** → **Take over**, sign in on its screen (first GitHub as gitteromri-ux, then Google gitter.omri@gmail.com, then Facebook/Meta, Vercel, Cloudflare, ActiveCampaign — whichever it asks for), click **Give control back**. It remembers every login.

**B6. Check and lock it in.** Its first message must contain the same proof as Instinct (budgets with time, 1440305917310328, lla-ac-events.vercel.app/api/meta/capi, 26 Oct 2026, website statuses, routines created, three decisions). Then send:
`Save all of this as skill "operator-os" and confirm it loads on every task.`
Optional 1-minute safety: Settings → Approvals → add "require approval" for sending emails, publishing/deploying, deleting, buying, and any change in Meta, Vercel, Cloudflare, ActiveCampaign or GitHub main. Then the bot can never change anything live without you tapping approve.
