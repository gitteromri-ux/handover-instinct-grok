# Critique Checklist — The Final QA Pass (Step 4)

Run this before sharing ANY deliverable. Judge the work like an awards jury. If any item fails, fix it and re-check. Do not ship work that wouldn't post to a 10M-follower feed.

## 1. The 1-second test
- [ ] Is there ONE instantly-readable hero idea? Can a stranger "get it" in under a second?
- [ ] Is the focal point unmistakable, or does the eye wander?

## 2. Depth & realism (signature)
- [ ] Real layered shadows (2–3 stacked), not a single flat drop shadow?
- [ ] Clear foreground/midground/background separation via scale, blur, and shadow?
- [ ] One consistent light direction across all shadows and highlights?
- [ ] Does it look premium/3D-real, or flat and "AI-generic"?

## 3. Typography
- [ ] Distinctive display + clean workhorse pairing (no Arial/Times defaults)?
- [ ] Dramatic, intentional scale contrast between headline and body?
- [ ] Headlines tracked and kerned by eye; no awkward letter pairs?
- [ ] Text legible at the target size (thumbnail = legible at 120px wide)?

## 4. Color
- [ ] Committed point of view: dominant + precise accent + controlled neutrals?
- [ ] Avoids pure #FFF / #000 for large fields (uses rich off-white / near-black)?
- [ ] Accent used sparingly to drive the eye (CTA / one hero word / glow)?
- [ ] Strong contrast split (light/dark or saturated/neutral)?

## 5. Composition & polish
- [ ] Confident negative space — premium, not crammed?
- [ ] Optical alignment correct (trust the eye, not just the grid)?
- [ ] Consistent rhythm/spacing; nothing accidentally misaligned?
- [ ] Exactly one bold "viral hook," executed cleanly?

## 6. Format & platform fit
- [ ] Correct aspect ratio / size for the target platform?
- [ ] Key content clear of UI-overlap zones (Reels/Stories top & bottom)?
- [ ] Single, obvious CTA where relevant?

## 7. Web/code-specific (when applicable)
- [ ] Fully responsive; looks premium on mobile, not just desktop?
- [ ] Layered shadows, premium web fonts, and intentional motion present?
- [ ] Accessible: sufficient contrast, focus states, `prefers-reduced-motion` honored?
- [ ] Actually inspected the rendered result (not assumed)?

## 8. Motion/video-specific (when applicable)
- [ ] Striking hook frame in the first second?
- [ ] Clear beat structure (hook → build → payoff → CTA)?
- [ ] Type animation enters with weight; cuts land on the beat?
- [ ] Loop-able where useful?

## Final gate
- [ ] Would the world's #1 viral designer post this? If not — iterate before sharing.
